# Gcina Avatar V2 model

The bundled GLB is the [Gcina Avatar V2 asset from commit 0837b18](https://github.com/ChumaMike/gcina/blob/0837b18d539a14c48007b35ad967b63c0181e06e/web/public/avatars/gcina-v2.glb).
It uses MakeHuman community mesh, morph, skeleton and skin-weight assets under
[CC0 1.0](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/LICENSE.md#c-meshes-targets-and-proxy-meshes).
Gcina authored the uniform, hair, facial details and materials. The original
[asset sources and Blender conversion instructions](https://github.com/ChumaMike/gcina/blob/0837b18d539a14c48007b35ad967b63c0181e06e/web/assets/avatar-source/README.md)
are recorded alongside the authored model.

The file is served from the dashboard's existing static media path so it is
available to both owner and judge sessions.
