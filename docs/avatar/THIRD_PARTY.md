# Avatar V2 asset provenance

The anatomical mesh, morph target, skeleton and vertex weights are MakeHuman
community **CC0 1.0** graphical assets. Attribution is provided for transparency,
although CC0 does not require it. Source files, licence, pinned revision and
checksums are in [web/assets/avatar-source](../../web/assets/avatar-source/README.md).
The GPL-licensed MakeHuman program is not bundled, executed or imported.

The garment shaping, hair construction, face accessories, Gcina shield,
materials and conversion script are authored in this repository. Blender 4.3.2
exports the GLB; Blender itself is not distributed. There are no external image
textures, voice recordings, proprietary avatar services or runtime model URLs.

Three.js and GLTFLoader reuse the project's installed Three.js 0.180.0 (MIT).
The self-contained HTML retains the bundled library licence comments.
Browser SpeechSynthesis voices belong to the user's browser/device; no voice
files are distributed or downloaded by Gcina. Some installed browser voices
may use their provider's network speech service.
